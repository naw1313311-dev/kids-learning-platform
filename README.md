# منصة أبجد التعليمية

منصة تعليمية تفاعلية للأطفال لتعلم الحروف الهجائية والأرقام

## المميزات

✅ تعلم 8 حروف هجائية بصور وأمثلة
✅ تعلم 10 أرقام بطريقة تفاعلية
✅ ألعاب تعليمية تفاعلية
✅ نظام نقاط ومكافآت
✅ تصميم جذاب وملون مناسب للأطفال
✅ أصوات عربية واضحة
✅ متوافق مع جميع الأجهزة
✅ تطبيق Next.js احترافي

## التثبيت والتشغيل

```bash
# تثبيت الحزم
npm install

# تشغيل المشروع محليًا
npm run dev

# بناء المشروع للإنتاج
npm run build

# تشغيل المشروع بعد البناء
npm start
```

## الروابط والصفحات

- الرئيسية: `/`
- الحروف: `/letters`
- الأرقام: `/numbers`
- الألعاب: `/games`
- التقدم: `/progress`
- تسجيل الدخول: `/login`

## التقنيات المستخدمة

- Next.js 14 (React Framework)
- TypeScript
- Tailwind CSS (للتصميم)
- Framer Motion (للحركات)
- React Icons (الأيقونات)
- Web Speech API (لتشغيل الصوت)

## الميزات المتقدمة

✨ نظام نقاط يحفظ في localStorage
✨ صوت عربي واضح ومباشر
✨ تصميم ريسبونسيف (متوافق مع جميع الأحجام)
✨ حركات وتأثيرات سلسة
✨ واجهة سهلة الاستخدام للأطفال

## النشر

يمكن نشر المشروع على:
- Vercel (الأسهل والأسرع)
- Netlify
- AWS
- أي خادم يدعم Node.js
